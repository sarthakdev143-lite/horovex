## 🏛️ Architectural Pillars at a Glance

1. **Initial 5 Probabilities $\to$ `+5 More Possibilities` (Horizontal Expansion)**:
   - **Wave 1 (Nodes 1–5)**: Baseline canonical probabilities (~80% mass).
   - **Wave 2 (Nodes 6–10)**: Second-order & contrarian possibilities carved from reserved unexplored phase-space mass.
   - **Wave 3+ (Nodes 11–15+)**: High-impact tail risks, Black Swans, and asymmetric 10x opportunities.
2. **Infinite Vertical Recursion**:
   - Every predicted node can become the new origin nexus ($T_0 \to T_1 \to T_2 \to \dots \to T_n$).
   - Users can either **auto-project** what happens next or **inject a custom action/intervention** before branching.
3. **The AI Mentor & Golden Path Engine**:
   - Combines **Expected Utility ($E[U]$)**, **Reversibility Index (Type 1 vs. Type 2 doors)**, and **10-Year Regret Minimization** to illuminate the optimal trajectory in warm champagne gold (`#D4AF37`).
   - Provides interactive **60 FPS Sensitivity Levers** (*"How to Bend the Odds"*), a **14-Day Action Playbook**, and **30/60/90-Day Tripwires**.
4. **Obsidian Chronometry Spatial Experience**:
   - Engineered with React Three Fiber, Three.js, custom GLSL spline shaders, and glassmorphic precision telemetry HUDs—zero generic templates.

## ✅ Locked-In Founder Alignment Decisions

1. **AI Model / Provider Architecture**:
   - **Multi-provider AI adapter** (`Gemini` / `OpenAI` / `Anthropic`) paired with a **built-in intelligent simulation engine fallback** so the application works out-of-the-box with or without external API keys configured.
2. **Pre-Simulation Calibration ("The Clarifying Pulse")**:
   - **Adaptive Entropy Gating**: Only prompt with the 3 quick clarifying questions when the user's situation input is short or ambiguous (always with a 1-click *"Skip & Simulate Immediately"* option); when the input is already detailed, launch directly into generating Wave 1 (Initial 5 Probabilities).
3. **Entry Experience & Authentication Flow**:
   - **Luxury 3D Hero/Landing Experience** that transitions seamlessly into the live **3D Multiverse Observatory**, supporting both **Instant Guest Sandbox** persistence and **Supabase Auth** to save/sync across devices.
4. **User Intervention Mode on Recursive Nodes**:
   - Every node supports both **Passive Auto-Projection** (*"Show me the next 5 most probable outcomes"*) and **Active Action Injection** (*"Assuming this happens, here is the move I make next"*).
5. **Product Name & Visual Signature**:
   - **HOROVEX** with the **Obsidian Chronometry** aesthetic (`#050507` Deep Void Obsidian, `#D4AF37` Champagne Gold for the Mentor's Golden Path, and Spectral Cyan/Emerald/Violet probability filaments).
