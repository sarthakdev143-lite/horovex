## 🛠️ Core Tech Stack

- **Framework**: Next.js (App Router, TypeScript)
- **3D Spatial Engine**: Three.js, React Three Fiber (`@react-three/fiber`), `@react-three/drei`, `@react-three/postprocessing`, Custom GLSL Shaders
- **Styling & Motion**: Tailwind CSS, Framer Motion, Obsidian Chronometry Design System
- **Database & Auth**: Supabase (PostgreSQL, `ltree` hierarchical indexing, `pgvector` embeddings, Row-Level Security)
- **Decision Intelligence**: Multi-stage structured LLM pipeline + Deterministic Bayesian & Bellman Utility Engine
